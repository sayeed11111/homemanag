# Home Manager

## 1. Что это

Веб-приложение для семьи. Родитель нажимает большую кнопку («Иди кушать», «Делай уроки», «Позвони мне»…) — указание приходит на телефон ребёнка со звуком, ребёнок отвечает одним нажатием: «Хорошо», «Готово» или «Нужна помощь». Работает в браузере телефона, без магазина приложений и без своего сервера; языки — английский, узбекский, русский.

Ссылка на приложение: https://<логин>.github.io/<репозиторий>/

(По этой ссылке открывается лендинг; само приложение — `…/app.html`.)

## 2. Как пользоваться

**Родитель**
1. Открыть `app.html` (или «Get started» на лендинге) → создать аккаунт: имя и PIN из 4 цифр.
2. «Я родитель».
3. «Создать семью» — ввести название (например, «Каримовы»).
4. «Отправить ссылку» (Telegram или любое приложение) или «Скопировать ссылку» — отправить её на телефон ребёнка.

**Ребёнок**
1. Открыть ссылку-приглашение на своём телефоне.
2. Создать аккаунт → «Я ребёнок».
3. Всё: ребёнок уже в семье (код взят из ссылки). Родитель увидит его, как только откроет приложение. Без ссылки код можно ввести вручную.

**Второй родитель** — аккаунт → «Я родитель» → «У меня есть код семьи» → ввести код (он есть во вкладке «Семья»). Можно и просто открыть ту же ссылку-приглашение — код подставится сам.

**Дальше**
- Родитель выбирает, кому (одному ребёнку или «Всем детям»), и нажимает кнопку. «Срочно» — указание придёт с громким сигналом. Можно написать своё указание или добавить свою кнопку («Изменить» → «Новая кнопка»).
- Ребёнок видит указание со звуком и вибрацией и отвечает «Хорошо» / «Готово» / «Нужна помощь». Сам он тоже может написать родителям готовой кнопкой («Забери меня», «Я дома»…; «Мне нужна помощь» уходит как срочное).
- У каждого указания родитель видит статус: «Отправляется…» → «Отправлено» → «Прочитано» → ответ ребёнка.
- Звук браузер разрешает только после первого нажатия на страницу: если видна плашка «Нажмите здесь, чтобы включить звук» — нажать её. Системные уведомления включаются в разделе «Уведомления».
- Чтобы открывать как обычное приложение: меню браузера → «Добавить на главный экран».

## 3. Как это работает внутри

- **Своего сервера нет.** Каждый телефон хранит свои данные в `localStorage` (ключи начинаются с `hmx_`): аккаунты, семью, журнал событий семьи (последние 600 событий за 30 дней), очередь отправки.
- **Доставка — через ntfy.sh**, бесплатный публичный ретранслятор сообщений без регистрации. Телефоны семьи слушают один канал (живой поток Server-Sent Events) и отправляют в него события в виде JSON.
- **Код семьи** — 16 букв и цифр (без похожих 0/O и 1/I), например `ABCD-EFGH-JKLM-NPQR`. Он и есть имя закрытого канала: `hmx-<код>`. Угадать его перебором нереально: 32¹⁶ ≈ 10²⁴ вариантов.
- **Всё, что делает семья, — события в общем журнале:**

  | Событие | Кто отправляет | Что значит |
  |---|---|---|
  | `hello` | любой | «я в этой семье»: имя и роль (родитель передаёт ещё название семьи) |
  | `cmd` | родитель | указание одному ребёнку или всем детям |
  | `seen` | телефон ребёнка | указание показано на экране → статус «Прочитано» |
  | `reply` | ребёнок | ответ: хорошо / готово / нужна помощь |
  | `msg` | ребёнок | быстрое сообщение родителям |

  `hello` телефон отправляет при входе в семью, а потом при открытии приложения, если с прошлого прошло больше 3 часов; увидев новичка, остальные отвечают своим `hello`, чтобы новичок узнал всю семью.
- **Проверка входящего.** Писать в канал может любой, кто знает код, поэтому каждое событие из сети пересобирается поле за полем (`HMCore.cleanEvent`): лишнее отбрасывается, текст обрезается, мусор игнорируется. Текст выводится только как текст, не как HTML.
- **Очередь отправки (outbox).** Событие сначала сохраняется на телефоне и только потом отправляется. Нет интернета, ошибка сервера или «слишком много запросов» — повтор через 8 секунд и сразу, как только интернет появился. Плохая связь только задерживает указание, но не теряет его.
- **Догон пропущенного.** При открытии приложения, при возврате в него и после восстановления связи телефон запрашивает всё, что пришло с момента последнего полученного сообщения (или за последние 12 часов). Повторы отбрасываются по id события.

## 4. Ограничения

- **ntfy.sh хранит сообщения 12 часов.** Если ребёнок не открыл приложение за 12 часов, указание до него уже не дойдёт — у родителя будет статус «Не доставлено» и кнопка «Отправить ещё раз».
- **Кто узнал код семьи, тот может читать канал** (и писать в него). Не публикуйте код и ссылку-приглашение в открытых чатах.
- **Лимиты ntfy.sh для анонимных пользователей:** около 60 запросов подряд, дальше 1 запрос в 5 секунд с одного IP-адреса, и около 250 сообщений в сутки с одного IP. Одно нажатие — это 1–3 сообщения, семье этого с запасом хватает; при превышении события ждут в очереди и уходят позже.
- **Уведомления и звук работают, пока приложение открыто или недавно свёрнуто.** Закрытый браузер уведомлений не получает: для настоящих push-уведомлений нужен свой сервер, а у статического сайта на GitHub Pages его нет. На iPhone системные уведомления сайта доступны только после «Добавить на экран „Домой“» (iOS 16.4 и новее).
- **PIN хранится только на этом телефоне и настоящей защитой не является** — он лишь не даёт брату или сестре зайти в чужой аккаунт на общем телефоне.
- **Данные живут только в этом браузере.** Очистили данные сайта или открыли другой браузер — аккаунта там нет; вернуться в семью можно по коду.
- **ntfy.sh — сторонний сервис без гарантий:** он может быть недоступен или изменить правила.

## 5. Как выложить на GitHub Pages

1. На github.com: **New repository** → имя (например, `home-manager`) → **Public** → **Create repository**.
2. **Add file → Upload files** → перетащить **содержимое** папки `home-manager` (все файлы и папки `css`, `js`, `img`, `tests`, а не саму папку — `index.html` должен лежать в корне репозитория) → **Commit changes**.
3. Проверить, что загрузился `.nojekyll` (скрытые файлы иногда не перетаскиваются). Если его нет: **Add file → Create new file** → имя `.nojekyll`, содержимое пустое → **Commit changes**. Он говорит GitHub Pages отдавать файлы как есть, без обработки Jekyll.
4. **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main**, папка **/ (root)** → **Save**.
5. Подождать около минуты (ход публикации виден во вкладке **Actions**) и открыть `https://<логин>.github.io/<репозиторий>/`.

Лендинг — `index.html`. Стартовая страница приложения — `app.html`: она сама решает, какой экран открыть, с неё же стартует значок на главном экране, и на неё ведут ссылки-приглашения (`app.html?join=КОД`). Все пути в проекте относительные, поэтому сайт работает и по адресу с подпапкой `/<репозиторий>/`.

## 6. Как проверить у себя на компьютере

```bash
cd home-manager
python -m http.server 8000
```

Открыть http://localhost:8000 (лендинг) или http://localhost:8000/app.html. Нужен интернет: доставка и локально идёт через ntfy.sh.

**Два «телефона» на одном компьютере** — у каждого должно быть своё хранилище:
- два сервера на разных портах — `python -m http.server 8001` и `python -m http.server 8002` в двух терминалах (разный порт = отдельный `localStorage`). Ссылка-приглашение, созданная на 8001, ведёт на 8001 — во втором окне замените порт на 8002 или введите код вручную;
- или обычное окно + окно инкогнито (данные инкогнито пропадут, когда его закроете).

Открывать файл двойным щелчком (`file://…`) не рекомендуется: там не работают service worker, уведомления и установка.

## 7. Тесты

```bash
node --test tests/core.test.js
```

Проверяется `js/core.js`: коды семьи, проверка входящих событий, сборка журнала, статусы доставки. Нужен Node.js 18 или новее.

**Сквозной тест** `tests/e2e.js` проходит весь путь на двух «телефонах» (сайт на портах 8101 и 8102) через настоящий ntfy.sh: лендинг → регистрация родителя → семья → ссылка-приглашение → регистрация ребёнка → указание → «Прочитано» → ответ → сообщение ребёнка → срочное своё указание → своя кнопка → смена языка → перезагрузка → выход и вход. Нужны Chrome или Edge и библиотека `puppeteer-core`. Ставьте её **вне** папки проекта, чтобы `node_modules` не попал на GitHub:

```bash
mkdir ../e2e-tools && cd ../e2e-tools && npm i puppeteer-core && cd -
NODE_PATH=../e2e-tools/node_modules node tests/e2e.js
```

(Windows PowerShell: `$env:NODE_PATH="..\e2e-tools\node_modules"; node tests/e2e.js`.) Путь к браузеру можно задать в `BROWSER_PATH`, папку для скриншотов — в `SHOTS_DIR`.

## 8. Структура файлов

| Файл | Что делает |
|---|---|
| `index.html`, `css/style.css`, `js/main.js` | лендинг |
| `app.html` | стартовая страница приложения: отправляет на нужный экран, принимает ссылки-приглашения |
| `register.html` | создание аккаунта: имя и PIN |
| `login.html` | вход: выбрать своё имя на этом телефоне и ввести PIN |
| `role.html` | выбор роли: родитель или ребёнок |
| `family.html` | создать семью и пригласить детей или присоединиться по коду |
| `parent.html` | экран родителя: кнопки-указания, история, семья |
| `child.html` | экран ребёнка: указания, ответы, сообщения родителям |
| `css/app.css` | стили экранов приложения |
| `js/core.js` | чистая логика: коды, проверка событий, журнал → то, что показывают экраны |
| `js/store.js` | всё, что хранится на телефоне (`localStorage`) |
| `js/i18n.js` | тексты на EN / UZ / RU и переключатель языка |
| `js/presets.js` | готовые кнопки родителя и ребёнка |
| `js/ui.js` | общие помощники: элементы, значки, окна, звук, вибрация, уведомления, «поделиться» |
| `js/bus.js` | доставка через ntfy.sh: поток, догон пропущенного, очередь отправки |
| `js/family.js` | связь аккаунта с семьёй: журнал, `hello`, отправка событий |
| `js/flow.js` | какой экран кому открыть + общая настройка каждой страницы |
| `js/auth.js` | регистрация, вход, выбор роли, семья |
| `js/parent.js` | логика экрана родителя |
| `js/child.js` | логика экрана ребёнка |
| `tests/core.test.js` | тесты для `js/core.js` |
| `tests/e2e.js` | сквозной тест: два «телефона» через настоящий ntfy.sh |
| `manifest.webmanifest` | установка на главный экран: название, цвета, значки |
| `sw.js` | service worker — только для уведомлений; кэша нет специально, чтобы обновления доходили сразу |
| `img/` | значки приложения (SVG и PNG) |
| `.nojekyll` | GitHub Pages отдаёт файлы как есть |
